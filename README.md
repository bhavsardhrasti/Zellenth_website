# Zellenth

A real-time laminate door visualizer for an Ahmedabad-based laminate door manufacturer. Guests
browse a catalogue of doors and laminates and preview any laminate on any door before submitting
a quote inquiry.

Single Next.js full-stack app — see `ai/` for the project spec, tech stack, coding rules, and
build phases (not checked into this repo).

## Getting Started

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to see the result.

## Scripts

- `npm run dev` — start the dev server
- `npm run build` — production build
- `npm run lint` / `npm run lint:check` — ESLint (fix / check-only)
- `npm run format` / `npm run format:check` — Prettier (fix / check-only)
- `npm run type-check` — `tsc --noEmit`

## Deploy

Deploys to Vercel as a live server (Route Handlers, Server Actions, ISR) — not a static export.
